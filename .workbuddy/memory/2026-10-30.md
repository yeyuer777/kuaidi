# 2026-10-30

## 取件码 App（PickupCode）— 完整交付

用户需求：提取各快递取件码的 iOS App，指定 iPhone + 免费自签安装。

**关键约束与决策**
- iOS 禁止第三方读短信 → 自动收集走快捷指令「收到信息」自动化 + App Intents（`openAppWhenRun = false`，静默入库不弹前台）
- 免费 Apple ID 签名不支持 App Groups → 放弃 Share Extension，改为单 Target + App Intent 直接写 Documents 文件，配 `pickupcode://parse?text=` URL 入口兜底
- 用户后补「巨魔手机」→ TrollStore 安装，永久有效，CI 只需产出 unsigned ipa（`CODE_SIGNING_ALLOWED=NO` + zip Payload），不走 Sideloadly
- 「输入手机号查各大平台」不可行（无开放接口、有风控、App Store 必拒）→ 只做被动解析

**架构**
- `PickupCode/Parser/` 规则引擎（`PickupRules.swift` 正则库 + `PickupParser.swift`），数据在 `Models/`
- 取件点品牌与快递公司拆成两个字段（`merchant` / `courier`）——回归测试暴露的建模缺陷
- 三个入口：快捷指令、粘贴、Vision OCR 截图识别

**验证方式（无 Xcode 环境）**
- `Scripts/verify_rules.py`：规则库 Python 等价实现，20 条真实样本（16 应提取 + 4 应拒绝），**20/20 通过**
- `Scripts/check_swift_syntax.py`：Swift 词法扫描 + 括号配平，15 文件 0 问题

**自查修掉的 3 个真实缺陷**
1. `.onChange` 挂到 `WindowGroup`（Scene）上 → 编译错误，scenePhase 监听移到 RootView
2. `PickupRepository.append` 去重 Set 导致「字段补全」是死代码 → 改为逐条指纹比对 + merged
3. 网点正则从任意中文串起匹配，把「您的快递已放入丰巢智能柜」整句当网点名 → 加动词锚定
